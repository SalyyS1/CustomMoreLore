Addon Paper cho MMOItems. Lore được dựng từ dữ liệu MMOItems và giữ native fallback khi runtime không đủ capability.
Paper addon · MMOItems

Lore của item, theo đúng cách server của bạn muốn.

CustomMoreLore cho phép ghép nhiều stat trên một dòng, tạo block lore riêng, ẩn separator khi thiếu stat và giữ nguyên dữ liệu gốc của MMOItems.

Layout đầu tiên
layout:
  - '<gray>⚔ #attack-damage# <dark_gray>| <aqua>#attack-speed#'
  - '<yellow>✦ #critical-strike-chance#'
  - '#abilities#'
  - '#lore#'

1. Cài đặt

  1. Đặt CustomMoreLore.jar vào thư mục plugins/.
  2. Đảm bảo MMOItems và MythicLib đã được cài trên server. PlaceholderAPI là tùy chọn.
  3. Khởi động server một lần để tạo config.yml và formats.yml.
  4. Chỉnh plugins/CustomMoreLore/formats.yml, sau đó chạy /cml reload.
Item không match profile hoặc gặp capability không được hỗ trợ sẽ giữ native lore. Plugin không sửa language file, template hay NBT của MMOItems.

2. Layout DSL

Mỗi phần tử trong layout là một dòng. Chuỗi thường giữ nguyên khoảng trắng; row và columns dùng khi cần tự bỏ phần tử thiếu.

Row có separator động
- row:
    parts:
      - text: '<gray>⚔ '
      - token: attack-damage
        render: fragment
      - token: attack-speed
        render: value
    join: ' <dark_gray>| '
    absent: remove-part
Columns gọn hơn
- columns:
    - token: attack-damage
      render: fragment
      absent: remove
    - token: attack-speed
      render: value
      absent: remove
  gap: ' <dark_gray>| '

Render mode

ModeÝ nghĩa
fragmentDùng format, label, màu và locale do MMOItems cung cấp.
valueDùng giá trị thô để tự định dạng trong layout.
blockDành cho block nhiều dòng như abilities, elements, effects hoặc lore.

3. Profile và thứ tự match

Profile được compile thành snapshot immutable. Reload lỗi không thay thế snapshot đang chạy.

Ưu tiênKhai báoVí dụ
1Item cụ thểprofiles.items.SWORD:sunblade
2Loại itemprofiles.types.SWORD
3Mặc địnhprofiles.default
profiles:
  default:
    layout: ['#lore#']
  types:
    SWORD:
      extends: default
      layout:
        - '<gray>⚔ #attack-damage# | #attack-speed#'
  items:
    SWORD:sunblade:
      priority: 100
      layout:
        - '<gold>Sunblade'
        - '#attack-damage#'

extends và parent đều được chấp nhận trong cùng bucket. Profile item có priority cao hơn sẽ thắng khi cùng bucket.

4. Tokens và placeholder

MMOItems

#attack-damage#, #attack-speed:value#, #abilities#, #elements#, #effects#, #lore#, #native-lore#.

Placeholder

%player_name% cho PlaceholderAPI; {player_name} hoặc [level] cho MythicLib parser.

Placeholder phụ thuộc viewer chỉ dùng cho /cml preview. Không ghi output riêng của người chơi vào ItemStack dùng chung.

5. Lệnh và quyền

LệnhTác dụng
/cml reloadLoad, validate và activate snapshot mới.
/cml validateKiểm tra cấu hình hiện tại.
/cml debug itemXem MMOItems identity, profile, capability và metrics.
/cml preview <profile>Preview trong memory với viewer hiện tại.
/cml editor <profile>Mở GUI draft, thêm row bằng chat, preview và save.

Quyền tổng: custommorelore.admin. Quyền riêng: custommorelore.reload, validate, debug, preview, editor, reformat.

6. Tương thích

  • Compile trên API chung để chạy Paper 1.20.x và 1.21.x.
  • MMOItems và MythicLib là dependency do server cung cấp, không shade vào jar.
  • Hook lore MMOItems hiện là synchronous/deprecated; repair async là best-effort.
  • Tooltip item được giữ native nếu profile chưa bật chính sách replace rõ ràng.

7. Xử lý lỗi

Stats không hiện

Chạy /cml debug item, kiểm tra item type/ID và chính tả stat ID. Dùng render: fragment nếu muốn format MMOItems.

Separator bị dư

Đổi từ chuỗi thường sang row hoặc columns với absent: remove.

Reload bị từ chối

Xem log server để biết source line. Snapshot cũ vẫn được giữ nếu config mới có lỗi.

Preview có nhưng item thật không có

Đó thường là placeholder phụ thuộc viewer. Lore persistent chỉ nhận output viewer-independent.
